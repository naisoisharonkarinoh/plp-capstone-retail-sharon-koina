# Dataset Documentation

## Project
Large-Scale Supermarket Sales and Customer Behaviour Analysis.

## Data Source
The dataset is synthetically generated using Python, NumPy and pandas for this PLP Data Analytics Capstone project.

## Date Accessed
20 October 2026.

## Licence
The dataset is generated for educational and portfolio purposes. It does not represent actual supermarket transactions.

## Files
- `transactions.csv`: Sales transaction records, including dates, product IDs, customer IDs, branch IDs, quantities and sales amounts.
- `products.csv`: Product names, categories and unit prices.
- `branches.csv`: Supermarket branch names and identifiers.
- `customers.csv`: Pseudonymous customer IDs and customer segments.

## Ethics and Privacy Statement
The dataset contains synthetic records and does not use real customer information. Customer IDs are generated identifiers rather than real identities. No personal names, telephone numbers, email addresses or other direct personal identifiers are included. Published reports will present aggregated sales and customer-segment information rather than individual-level records.

## Reproducibility
The Python data-generation script will be included in the project repository so that another analyst can reproduce the dataset.
