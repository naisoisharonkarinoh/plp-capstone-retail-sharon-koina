# Large-Scale Supermarket Sales and Customer Behaviour Analysis

## Project Overview
This Data Analytics Capstone Project analyses synthetic supermarket transaction data to explore sales performance, product categories, branch revenue, and customer purchasing patterns.

## Business Problem
Retail managers need reliable sales information to compare branches, monitor revenue trends, understand product performance, and make informed decisions about inventory, promotions, and resource allocation.

## Project Objectives
- Clean and validate transaction data.
- Analyse sales and revenue using Python and SQL.
- Compare branch and product category performance.
- Explore customer spending patterns.
- Conduct a statistical comparison of transaction values between Nairobi and Mombasa.
- Present findings and recommendations for business decision-making.

## Dataset
The project uses synthetic data consisting of:
- 50,000 transactions
- 20 products
- 5 supermarket branches
- 5,000 customer records

The dataset is generated for educational purposes and does not represent real customers or actual supermarket sales.

## Project Structure
- `data/` — datasets, data documentation, and data generation script
- `notebooks/` — cleaning, exploratory data analysis, and statistical analysis

- `sql/` — SQL analysis queries
- `reports/` — executive summary and project reports
- `requirements.txt` — Python dependencies

## How to Run
1. Download or clone this repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open the notebooks in Google Colab or Jupyter.
4. Run `01_cleaning.ipynb`, `02_eda.ipynb`, and `03_analysis.ipynb` in order.

The notebooks load the CSV files from this repository's `data/` folder. An internet connection is required for this data-loading method.

## Expected Business Value
The analysis demonstrates how sales data can support performance monitoring, branch comparisons, product planning, and evidence-based business recommendations.

## Limitations
The data is synthetic, so findings are illustrative and must not be treated as evidence of actual supermarket performance. Recommendations should be validated against real business data.
